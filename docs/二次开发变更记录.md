### 调用链与重点入口

`trip.py:24` 接收并校验请求 → `plan_trip():182` 设置总超时 → `_plan_trip():249` 开启任务独立会话 → 景点搜索/详情 → 天气查询 → 酒店搜索/详情 → `_generate_plan():223` 产生结构化结果 → `_validate_and_ground():132` 校验并采用真实资料 → 返回 `TripPlanResponse`。

无有效景点或模型调用失败时返回失败；天气/酒店不可用则返回 `degraded`，清空缺失信息并说明原因。价格仍为估算，不能视为实时查询报价。工具记录目前只在任务内存中使用，数据库持久化和后台展示尚未开始。
